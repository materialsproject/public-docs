# Upload Interface

Contribute your own materials data to a project, directly in the browser. This is the interactive, no-code counterpart to contributing data via the API; see [Contribute Data](../what-is-mpcontribs.md) for that approach.

The Upload Interface is organized into two tabs:

[**Upload tab**](upload-tab.md)**:** for adding new data to a project. Load a file (CSV, Excel, or Google Sheet), review and edit it in an editable grid, and submit it to create new contributions or update existing ones.

[**Edit tab**](edit-tab.md): for working with data that's already in a project. Load an existing project's contributions directly into the grid, edit values, delete rows or columns, and submit your changes, no re-upload required.

Use the Upload tab when you're bringing in new data from a file. Use the Edit tab when you want to delete, update, or clean up data that's already been contributed.
